# RACI and stakeholder communications
FDE: owns discovery, prototype, integration, workshops, documentation and handover evidence.
Customer data owner: accountable for source schemas and test dataset approval.
Security: approves authentication, data processing, threat model and residency.
Platform/SRE: owns deployment, logging, alerts and recovery.
Product: owns prioritized feature requests and feedback loop.
Customer Success: owns onboarding, adoption reporting and support training.
Weekly pilot sync: decisions, blockers, demonstrations, feedback, risks and next actions.
