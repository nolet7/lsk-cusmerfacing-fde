# Customer discovery and sales engineering
## Pre-call checklist
Identify decision maker, budget owner, champion, technical data owner, procurement constraints, travel/workshop needs and success metric.
## Questions
1. What account questions require switching between CRM, ERP and support?
2. Which API versions, OAuth scopes, fields, SLAs and rate limits exist?
3. What SQL engines and data freshness expectations apply?
4. Which information is confidential or regulated? What is the residence policy?
5. Who accepts the POC, owns onboarding and signs off security?
6. Which adoption metric makes a pilot economically useful?
## Demo script (20 minutes)
5m business pain and legacy app -> 5m API/SQL live walkthrough -> 5m account 360 briefing with evidence -> 3m safety/failure mode -> 2m next steps.
## Deliverables
Discovery notes, champion map, API inventory, sample JSON payload contracts, scope exclusions, estimated effort, mutual action plan and technical objections register.
